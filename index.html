Pipeline de CI/CD

Sempre que fazemos um push para o branch 'main', este é o processo que corre no GitHub Actions para validar a mensagem do commit e construir a imagem Docker:

name: CI/CD Pipeline

on:
  push:
    branches: [prod]

jobs:
  validate-commit:
    name: Validate commit message
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Validate commit message
        run: |
          COMMIT_MSG=$(git log -1 --pretty=%B)
          echo "Commit message: $COMMIT_MSG"
          if ! echo "$COMMIT_MSG" | grep -qE "^(feat|fix|ci|test|refactor|build): .+"; then
            echo "ERROR: Commit message must follow Conventional Commits format"
            exit 1
          fi
          echo "Commit message is valid"

A nossa pipelina valida se o commit começa pelas seguintes tags: feat | fix | ci | test | refactor | build
